# ZekaKati-Automation
Python tabanlı kısa video üretim otomasyonu. İçerik senaryoları için geniş dil modellerini, seslendirme için ElevenLabs teknolojisini, görsel materyaller için Pexels API altyapısını ve video kurgu süreçleri için MoviePy kütüphanesini kullanıldı.

Proje Amacı: Kısa formatlı video içeriklerinin üretim sürecini yazılımsal olarak otomatize etmek.

Proje Nasıl Çalışıyor: Belirlenen bir konu üzerinden yapay zeka ile metin oluşturulması, bu metnin ElevenLabs ile seslendirilmesi ve Pexels üzerinden ilgili videoların temin edilerek birleştirilmesi.

Teknik Yapı: Video kliplerin birleştirilmesi, ses dosyalarının eklenmesi ve altyazıların yerleştirilmesi işlemleri MoviePy kütüphanesi üzerinden yürütülür.
